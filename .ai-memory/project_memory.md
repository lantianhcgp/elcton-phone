# 同步开发约定

已确认范围：手机主编辑、手表查看/删除/导出，不做自动合并；新手机源码公开但凭据与私人课表不入库。
设备目标为尽可能所有支持 Wear Engine 且支持应用安装/P2P 的手表。FIT3 只是主真机；Lite 自主验收用朋友 hmlwsim。hmlwsim=浏览器仿真，不是官方或自研 lite-sim，不能证明真实连接、认证、堆或存储原子性。

术语：APPLIED 指已提交并回读的数据，不是 send success；rev 是本地保存计数，sourceRevision 是手机发布版；调测 HAP 绑定设备，不是全机型通装包。

基线选择：现役课程表持久化/取件码在 feat/lan-sync-probe，master 尚为旧形态。新 feat/wearengine-sync 从已读过的现役分支起，禁止在原工作树整包复制秘密。

安全：通信指纹为公开身份，私钥为秘密。公开前扫新提交与产物；不改现有工作树/浏览器修改，不删除手机共享存储。

验证：真实SDK AAR javap 确认 API；协议/存储采用逐行为 RED→GREEN；原始构建.app 在 hmlwsim 点击导航与多尺寸检查。UI整帧非黑不等于逐组件验收。

撤销条件：用户要求双主编辑、引入服务器或新平台真正不支持旧运行时时重新评估；单个FIT3失败不能据此删除全部其他机型支持目标。
