# hc课程表 Android 配套应用

手机主编辑、手表离线查看，通过 Wear Engine 发布课表快照。设备目标为尽可能覆盖支持应用安装和 P2P 通信的 Wear Engine 手表；FIT3 是当前主要真机调试设备，不是支持范围上限。

当前为开发阶段，尚未发布。源码公开，签名私钥、账号凭据和私人课表不入库。表端开发在 elcton 仓的独立 feat/wearengine-sync 分支；自主 Lite UI/协议验收使用 kqakqakqa 的 hmlwsim，真实授权与蓝牙结果单列。

## 首阶段

- 设备枚举、DEVICE_MANAGER 授权、安装状态、配对通信探针。
- ASCII JSON 与 CRC32、受控短消息分包、APPLIED 读回确认。
- 课堂编辑/导入、冲突处理与广泛分发仍在逐步实现，不将探针冒充完成产品。

## 构建

使用 GitHub Actions 与固定工具版本。生产签名经仓库 Secrets 注入，apk 签名验证不通过不输出交付产物。

## 隐私

仅处理本人录入的课程信息及选择同步设备所需的最小 SDK 信息，不采集健康、定位、通讯录等数据。实验日志不默认输出私人课表全文。没有自建云服务。
